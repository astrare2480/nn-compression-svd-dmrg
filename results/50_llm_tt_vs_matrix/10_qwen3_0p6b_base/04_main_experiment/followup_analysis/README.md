## 要点

### 分析 0（既存の CSV から）

- C4 の $\rho$ の低下を、分子 $(e_{M5}-e_{M2})/e_{M3}$ と分母 $(e_{M3}-e_{M2})/e_{M3}$ に分けると、42 セルすべてで分子が増え（主な 34 セルの中央値 0.070 → 0.105）、分母が減った（0.83 → 0.76）。片方だけ C4 の値にすると、$\rho$ の中央値は分子だけで 0.92 → 0.87、分母だけで 0.92 → 0.91。主に分子。
- 最終の M5 の停留性 $s_{\max}$ は $5.9\times10^{-5}$〜$7.3\times10^{-4}$（中央値 $2.6\times10^{-4}$）。03 の停留の基準 $10^{-6}$ には遠い（`als/full/*_history.csv` の最後の掃引）。
- L21_down は、較正の目的 $Q_\lambda$ でも M5 が M2 を上回る（較正の $\rho$ = 1.03・1.06。`evaluation/cells.csv` の `rho_calibration`）。

### 分析 1：較正の Gram 行列の固有方向ごとの誤差

較正の固有方向を、固有値の大きい順（較正データでよく来る順）に 4 つの帯に分けた。主な 34 セルの中央値：

| 帯（順位） | 1〜16 | 17〜64 | 65〜256 | 257〜 |
|---|---|---|---|---|
| 溝（M3 − M2）の割合（較正の重み） | 0.72 | 0.16 | 0.14 | 0.01 |
| M5 − M2 の割合（較正の重み） | 0.01 | 0.05 | 0.24 | 0.68 |
| M5 − M2 の割合（C4 の重み） | 0.00 | 0.03 | 0.18 | 0.78 |
| 向きの重みの比 C4 ÷ 較正（トークンあたり） | 0.83 | 0.82 | 1.08 | 1.65 |
| 向きの重みの比 WT-2 ÷ 較正 | 0.95 | 0.96 | 0.98 | 1.07 |

- WT-2 から C4 で増えた「M5 − M2」は、ほぼ 100% が 257 位以降から（34 セルすべてで増加）。
- down は、M5 が上位の帯で M2 より誤差が少なく、257 位以降で大きく負ける。C4 の重みの比は 1.82。
- 帯ごとに分けるときは、検証の Gram 行列の非対角を無視している。この近似は、正確な値の 88〜126%（中央値 96〜99%）を捉える。

### 分析 4：帯ごとの「M5 ÷ M2」（分析 1 の読み方の訂正）

分析 1 の「M5 − M2 の 68% が 257 位以降」は、「257 位以降で M5 が M2 の何倍も落とす」という意味ではない。帯ごとに比を測ると（主な 34 セルの中央値 [最小, 最大]、較正の重みつき）：

| 帯 | 1〜16 | 17〜64 | 65〜256 | 257〜 |
|---|---|---|---|---|
| M5 ÷ M2 | 4.58 [0.57, 21.5] | 4.01 [0.52, 10.9] | 1.59 [0.44, 3.88] | 1.35 [0.91, 2.06] |

- 倍率が大きいのは上位の帯。ただし M2 は上位の帯をほぼ完全に表すので、そこでの誤差の絶対値は小さく、差も小さい。
- 257 位以降は、M2 自身の誤差の大部分がある帯（低ランク近似が捨てる帯）。M5 はそこで M2 より 3〜4 割多く誤差を残す。もとが大きいので、それが M5 − M2 の大部分になる。
- 正しい言い方：「どちらも、較正データであまり来ない向きを大きく雑に扱う。M5 はそこで M2 より 3〜4 割多い。C4 はその向きに較正の 1.65 倍の入力を乗せるので、差が広がる」。「M5 だけが、M2 の保つ情報を落とした」ではない。
- 各帯に乗る較正データの入力の量（`input_share.csv`）：attention の入力では 1〜16 位に 62〜71%、257 位以降（768 本）に 9〜12%。down の入力（3072 次元）では 257 位以降に 28〜44%。257 位以降は、1 本ずつにはほとんど乗らないが、束では無視できない。
- 帯の区切り（16・64・256）は、03 で有効ランクが約 60 だったことから、その前後が分かれるように結果を見る前に決めた。別の区切りでの確認はしていない。

### 分析 2：attention の段階ごとの誤差（25%、WT-2）

k の相対二乗誤差（M2 / M3 / M5）：

| 層 | 点数 | softmax 後の重み | o の後 |
|---|---|---|---|
| L7 | 0.009 / 0.117 / 0.022 | 0.455 / 0.739 / 0.744 | 0.59 / 0.99 / 1.01 |
| L14 | 0.015 / 0.423 / 0.044 | 0.483 / 0.785 / 0.749 | 0.42 / 1.46 / 0.71 |
| L21 | 0.024 / 0.907 / 0.057 | 0.735 / 0.933 / 0.908 | 1.71 / 2.02 / 2.00 |

- k は点数までは $\rho$ 0.82〜0.96 だが、softmax の後で 0〜0.14 に落ちる。点数の誤差のうち softmax に効く成分（key の間の差を変える成分）の割合は、M2 と M5 でほぼ同じ。
- v は射影の段階で $\rho$ 0.64〜0.83、注目の重みで足し合わせた段階で崩れる（L21 で M5 の誤差 1.15 が M3 の 0.84 を超える）。
- q はどの段階でも $\rho$ 0.85 以上。

### 分析 3：attention sink（先頭のトークン）

- 注目のうち、区間の先頭のトークンに向かう割合：L7 0.48、L14 0.41、L21 0.69（WT-2 と C4 でほぼ同じ）。
- 先頭のトークンの attention の入力（正規化の後）の大きさは、ほかの位置の中央値の 0.33〜0.46 倍。
- k を先頭以外だけ置き換えると、softmax 後の重みの誤差は M2 0.01〜0.03、M5 0.02〜0.06（$\rho$ 0.93〜0.96）。先頭だけ置き換えると M2 0.43〜0.71、M5 0.72〜0.88。誤差のほぼ全部が先頭のトークンの k から来て、M2 でも壊れる。
- v を先頭だけ置き換えると、head ごとの出力の誤差は M2 0.02〜0.04、M3 0.03〜0.07、M5 0.21〜0.86。M5 だけが先頭のトークンの値を外す。先頭以外だけだと $\rho$ 0.85〜0.88。
