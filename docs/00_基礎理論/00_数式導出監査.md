## 3. historical sourceにある不整合の扱い

過去資料は学習過程の記録なので、**古い説明を無条件にそのまま転記しない**。

### 3.1 特異値energy

古いDMRG/SVD探索資料には、rank選択について

```text
特異値の和の99%を残す
```

という文章が残っている。

一方、同じ資料のコードでは

```python
s2 = s ** 2
```

としており、Frobenius energyの計算は特異値二乗和を使っている。

現在のSVDノートでは数学的に整合する

$$
\boxed{
E(r)
=
\frac{
\sum_{i=1}^{r}\sigma_i^2
}{
\sum_{i=1}^{k}\sigma_i^2
}
}
$$

へ統一する。

理由は

$$
\|W\|_F^2
=
\sum_{i=1}^{k}\sigma_i^2
$$

だからである。

したがって古い「特異値の和」はhistoricalな説明としては存在するが、**現在のcanonical理論式には採用しない**。

### 3.2 左・右特異ベクトル

古い探索資料の説明で入力側 / 出力側の言い回しが曖昧な箇所があっても、現在は

$$
W:\mathbb R^n\rightarrow\mathbb R^m,
$$

$$
\boxed{
Wv_i=\sigma_i u_i
}
$$

という作用とshapeを基準にする。

```text
v_i : 入力側
u_i : 出力側
```

へ統一した。

### 3.3 完全SVDの転置

完全SVDで

$$
W=U\Sigma V^{\mathsf T}
$$

なら、長方形$\Sigma$を含む転置は

$$
\boxed{
W^{\mathsf T}
=V\Sigma^{\mathsf T}U^{\mathsf T}
}
$$

である。

$\Sigma^{\mathsf T}$を落とさない。Reduced SVDで$\Sigma$が正方対角行列の場合だけ

$$
\Sigma^{\mathsf T}=\Sigma
$$

と簡略化できる。

## 4. 数式の記載ルール

非自明な式では必要に応じて次の順序を残す。

```text
定義
→ shape / 次元
→ 代入前の一般式
→ 途中の積・和・変形
→ 最終式
→ 必要なら具体値代入
→ その式が意味すること
```

「途中式」は単に行数を増やすことではない。少なくとも、

- なぜその転置なのか
- どのshape同士を掛けるのか
- なぜその分母なのか
- 何を相殺したのか
- 何を固定し、何を更新しているのか
- どの条件で式が成立するのか

が追えることを基準にする。

## 7. 誤差評価で追加確認した文字式

### 行列RMSE

$$
Y,\hat Y\in\mathbb R^{N\times D}
$$

なら、

$$
\boxed{
\operatorname{RMSE}
=
\frac{
\|Y-\hat Y\|_F
}{
\sqrt{ND}
}
}
$$

であり、分母は$N$ではなく全要素数$ND$。

### batchをまたぐRMSE

$$
\boxed{
\operatorname{RMSE}_{all}
=
\sqrt{
\frac{
\sum_b\|E^{(b)}\|_F^2
}{
\sum_bM_b
}
}
}
$$

と、二乗誤差和と要素数を累積してから平方根を取る。

### 期待output error

$$
\Delta W=W-W_r,
\qquad
C_x=\mathbb E[xx^{\mathsf T}]
$$

なら、

$$
\boxed{
\mathbb E
\left[
\|\Delta Wx\|_2^2
\right]
=
\operatorname{tr}
\left(
\Delta WC_x\Delta W^{\mathsf T}
\right)
}.
$$

$C_x$は平均を引いていなければ共分散ではなく**非中心化二次モーメント**。

### ReLU

$$
\boxed{
\|\operatorname{ReLU}(z)-\operatorname{ReLU}(z')\|_2
\le
\|z-z'\|_2
}
$$

をscalarの場合分けから導出した。

### logits margin

$$
m
=z_c-\max_{j\ne c}z_j
$$

に対し、

$$
\boxed{
\|\delta z\|_\infty<\frac m2
}
$$

なら元のargmaxを保つことを途中式から示した。これは十分条件であって必要条件ではない。

## 9. HOSVDで監査した重要点

Tensor自身のexact multilinear rankは

$$
\boxed{
\operatorname{rank}_{ML}(\mathcal X)
=
\left(
\operatorname{rank}(X_{(0)}),
\ldots,
\operatorname{rank}(X_{(N-1)})
\right)
}
$$

である。

一方、圧縮で指定する

$$
(R_0,\ldots,R_{N-1})
$$

はtarget Tucker ranks。

近似Tensorでは

$$
\boxed{
\operatorname{rank}(\hat X_{(n)})\le R_n
}.
$$

HOSVD factorは

$$
X_{(n)}=Q_n\Sigma_nV_n^{\mathsf T}
$$

から

$$
\boxed{
U^{(n)}
=
\begin{bmatrix}
q^{(n)}_1&\cdots&q^{(n)}_{R_n}
\end{bmatrix}
}
$$

と取る。

Pythonでは

```python
Q_n[:, :R_n]
```

であり、数学の1始まり表記をPythonの`[:,1:R_n]`へ直訳しない。

## 10. HOOIで監査した重要点

HOOIは直交factorのTucker近似

$$
\min
\|\mathcal X-\hat{\mathcal X}\|_F^2
$$

を交互更新する。

直交射影から

$$
\boxed{
\|\mathcal X-\hat{\mathcal X}\|_F^2
=
\|\mathcal X\|_F^2
-
\|\mathcal G\|_F^2
}
$$

なので、他factorを固定するとcore norm最大化へ変換できる。

対象modeのprojected unfoldingを$Z$、候補factorを$U$とすると、

$$
\max_{U^{\mathsf T}U=I}
\|U^{\mathsf T}Z\|_F^2
$$

$$
=
\max_{U^{\mathsf T}U=I}
\operatorname{tr}
\left(
U^{\mathsf T}ZZ^{\mathsf T}U
\right).
$$

$$
Z=Q\Sigma V^{\mathsf T}
$$

なら

$$
ZZ^{\mathsf T}
=Q\Sigma\Sigma^{\mathsf T}Q^{\mathsf T},
$$

よって上位$R_n$本の左特異ベクトルを取る更新になる。

これは添付のHOOI更新式を理解するために追加した**補足導出**。

## 11. Tucker-2で監査した重要点

$$
W
\in
\mathbb R^{C_{out}\times C_{in}\times K_h\times K_w}
$$

をchannel mode 0 / 1で圧縮すると、

$$
\boxed{
\hat W_{o,i,a,b}
=
\sum_{\alpha=1}^{R_{out}}
\sum_{\beta=1}^{R_{in}}
U^{out}_{o,\alpha}
G_{\alpha,\beta,a,b}
U^{in}_{i,\beta}
}
$$

となる。

forwardは

```text
C_in
→ U_in^T / 1x1
→ R_in
→ G / K_h×K_w
→ R_out
→ U_out / 1x1
→ C_out
```

で、3式を代入すると上のeffective weightへ戻ることを`20`で途中から示した。

一般MACsは

$$
\boxed{
\begin{aligned}
\operatorname{MACs}_{Tucker2}
={}&H_{in}W_{in}C_{in}R_{in}\\
&+H_{out}W_{out}R_{out}R_{in}K_hK_w\\
&+H_{out}W_{out}R_{out}C_{out}.
\end{aligned}
}
$$

入力・出力空間サイズが同じ場合だけ共通$HW$で括る。

## 15. 今後TT/MPS・DMRGで継承する基準

今後のTensor Networkでも同じ基準で

```text
tensorization / reshape
→ index / shape定義
→ unfolding / matricization
→ SVD
→ truncate
→ bond / core shape
→ contraction / reconstruction
→ error
→ parameter count
→ objective
→ sweep update
→ convergence
```

を途中式込みで残す。

特に、

- bond dimensionがどのindexか
- どのTensorを固定してどれを更新するか
- SVD前後でshapeがどう変わるか
- truncate errorがどの特異値に対応するか
- DMRGの局所目的とNNのtask lossをどう区別するか

を省略しない。
