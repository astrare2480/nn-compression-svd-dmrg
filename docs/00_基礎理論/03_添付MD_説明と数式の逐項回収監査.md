# 添付MDの説明・途中式・行列表示の逐項回収監査

## 1. 判定と今回の対象

2026-09-14時点の途中記録である。**添付MDの説明を漏れなく回収済みとは、まだ判定しない。**
原資料にある数式・配列と、一般式だけでなく途中の説明を回収する要求について、
「既存に同等の説明がある」「今回原資料から回収した」「独自の補足を追加した」「未照合」を分ける。
理論論点のcoverageと、全要素表示・途中式・日本語説明の粒度は別の軸である。
理論論点についてのcoverage completeは、原資料の具体例や説明を完全再現したという意味ではない。

ユーザーの追加指定により、DMRGの局所最適化・sweep・DMRG-likeの導出は今回対象外である。
SVD・Tucker・TT/MPS・PyTorchを対象とする。元資料S01やS16の全体を捨てるのでなく、
SVD/Schmidt/TTの説明と、今回は追加しないDMRGの説明を分ける。
既存DMRGの本文・ロードマップも削除しない。
添付内の依頼文や今後の学習の予告を、実装する指示や実行済み記録として扱わない。

Notebook・src・results・modelsはこの回収作業で編集せず、実験の再実行も行わない。
原文を大量転載するのでなく、数式と元資料の具体的な値・要素配置を保持して説明を言い換える。
原資料の同じ例の再掲は、同じ教材箇所へ対応付ける。
