# 依頼：候補 3 の結論（A の結果）の確認と、次の一手

前回の依頼（`03_after_first_token_bands.md`）への回答で「次は A（保存したコアで、先頭トークンの v の誤差の推移を測る）」となったので、計算しました。結果の読み方が妥当かの確認と、次の順番の相談です。目的は引き続き論文化です。

## 記号（前回と同じ）

- M2：較正 Gram 行列で白色化した SVD（同じランクの行列の最適）。M3：TT-SVD（較正を使わない）。M5：M3 から始め、較正の目的 $Q_\lambda = \|(W-\hat W)G_\lambda^{1/2}\|_F^2$ を下げる TT の ALS（$\lambda=10^{-6}$）。
- $R = W - \hat W$、$x_0$ は先頭トークンの attention の入力。
- 誤差はどれも「置き換えた誤差の二乗ノルム ÷ 元の値の二乗ノルム」（比は二乗ノルムどうし。出力の大きさの比ではない）。

## 前回の指摘への対応

- 「M5 の出力が元の 4〜16 倍」という言い方を、「誤差の二乗ノルムが元の出力の二乗ノルムの 4〜16 倍」に直した。
- README 冒頭の「新しい ALS は回していない」を、分析 1〜5 と分析 6 に分けた説明に直した。

## A の計算方法

- 対象：v_proj 25% の 3 セル（L7・L14・L21）。04 の M5（開始点）と、+10,000 掃引の間に 100 掃引ごとに保存した 100 個のコア。比べるため M2・M3 も。
- 検証データ：WikiText-2（285 区間）と C4（128 区間）。
- 量：
  - 射影の段階：先頭 $\|Rx_0\|^2/\|Wx_0\|^2$、先頭以外の同じ比。
  - head の出力・o の後の段階（前回の sink test と同じ定義）：sink ＝ v の出力を先頭の位置だけ置き換え、full ＝ 全位置で置き換え。q・k は元のままなので attention の重みは変わらず、差は $\Delta\text{heads} = \text{probs}\,\Delta V$ で直接計算。
- 検算：開始点のコアから作った行列は 04 の M5 と完全一致（差 0）。開始点と M2・M3 の head・o の後の値は、前回の sink test と相対差 $4\times10^{-7}$ 以内で一致。

## 結果（WT-2。M5 の開始点 → +10,000 掃引後。括弧は M2 / M3）

| セル | 射影・先頭 | 射影・先頭以外 | head・sink | o の後・sink | o の後・full |
|---|---|---|---|---|---|
| L7_v_25 | 4.170 → 4.156 (0.30 / 1.02) | 0.389 → 0.388 | 0.309 → 0.307 (0.020 / 0.072) | 0.304 → 0.326 | 0.631 → 0.652 (0.298 / 0.770) |
| L14_v_25 | 4.220 → 4.291 (0.54 / 1.00) | 0.254 → 0.254 | 0.205 → 0.210 (0.016 / 0.031) | 0.236 → 0.264 | 0.545 → 0.574 (0.239 / 0.791) |
| L21_v_25 | 16.26 → 15.85 (0.87 / 1.15) | 0.391 → 0.391 | 0.864 → 0.860 (0.044 / 0.061) | 0.712 → 0.736 | 0.969 → 0.991 (0.256 / 0.830) |

- 途中の 100 個のコアでも、射影・先頭は開始点から ±3% 程度、head・sink は ±4% 以内。M2 との差（射影・先頭で 8〜18 倍、head・sink で 13〜20 倍）に比べてずっと小さい。C4 も同じ傾向。
- o の後の誤差は少し増える（sink で +3〜12%、full で +2〜5%）。この間 $Q_\lambda$ は 0.04〜0.08% 下がり、$s_{\max}$ は $10^{-8}$ 程度まで下がっている。
- 先頭以外の射影の誤差はほぼ動かない（小数第 3 位まで同じ）。

## 私の結論（確認してほしい）

1. v で M5 が弱いのは、最適化の不足ではない。停留点のごく近くでも先頭の誤差は M2 の 8〜20 倍のまま。
2. 原因は較正の目的の重みづけ。先頭の入力は較正でまれな向き（固有値 257 位以降）に 35〜62% 乗っており、目的はそこでの誤差をほとんど数えない。一方、推論では先頭に attention が 41〜69% 集まる。
3. 分析 1〜5 と合わせて、「較正の重みづけと、実際に効く向きのずれ」が、v の弱さと C4 で差が縮みにくいことの両方を説明する。
