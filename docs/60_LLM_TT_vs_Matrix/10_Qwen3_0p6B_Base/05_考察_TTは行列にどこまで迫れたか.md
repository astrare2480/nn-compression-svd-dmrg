# 考察：TT は行列にどこまで迫れたか

## 1. このノートの役割

このノートでは、Qwen3-0.6B-Base の 3 層・7 射影・2 予算で TT 圧縮と行列の低ランク圧縮を比較した結果を、追加分析まで含めて考察する。実験条件と全結果は [[60_LLM_TT_vs_Matrix/10_Qwen3_0p6B_Base/04_本実験_複数の層と射影でのTTと行列の比較|04 本実験]]、ALS の長時間収束と初期値依存は [[60_LLM_TT_vs_Matrix/10_Qwen3_0p6B_Base/03_長いALSの収束確認と初期値依存|03 長い ALS]] を参照する。

ここで問うのは、単に「TT と行列のどちらが勝ったか」ではない。次の三つを分けて考える。

1. TT の metric ALS（M5）が、未調整の TT-SVD（M3）からどこまで改善したか。
2. 同じ較正目的に対する行列低ランク近似（M2）との差が、どこに残ったか。
3. 重み誤差の改善が、サブ層出力と NLL にどこまで伝わったか。

![[assets/qwen3_layer_projections.png]]

## 2. 比較したものと指標

**TT（Tensor Train）**とは、テンソル化した重みを複数の小さなコアの積で表す形式である。対して **rank-$r$ 行列近似**は、行列を階数 $r$ 以下の積で表す。対象は層 7、14、21 の `q_proj`、`k_proj`、`v_proj`、`o_proj`、`gate_proj`、`up_proj`、`down_proj` である。各射影を 50% または 25% のパラメータ予算に圧縮し、合計 42 セルを比較した。主解析 34 セルでは、ほぼ飽和していた `k_proj` と `v_proj` の 50% 条件 6 セル、および開発時条件の L14 `up_proj` 2 セルを除いている。

較正入力の非中心化二次モーメントを Gram 行列 $G$ とする。これは、入力方向ごとの出現量を表す行列である。重み $W$ と近似 $\hat W$ の相対出力誤差は

$$
e = \frac{\left\lVert (W - \hat W) G^{1/2} \right\rVert_F^2}
         {\left\lVert W G^{1/2} \right\rVert_F^2}
$$

で測った。M2 は、正則化した較正 Gram 行列に対する rank-$r$ 行列クラス内の厳密解である。M3 は TT-SVD、M3F は Frobenius ALS、M5 は Gram 行列を用いた metric TT ALS である。

M3 から M2 までの差を M5 がどれだけ埋めたかを、**gap closure（差を埋めた割合）**

$$
\rho = \frac{e_{\mathrm{M3}} - e_{\mathrm{M5}}}
             {e_{\mathrm{M3}} - e_{\mathrm{M2}}}
$$

で表す。$\rho=1$ なら M5 が M2 と同じ誤差、$\rho=0$ なら M3 から改善していない。ただし、分母が小さい条件や、M2 自体が下流機能を壊す条件では、$\rho$ だけで実用上の良否を判断できない。

## 3. まず事実として言えること

### 3.1 M5 は M3 と M2 の差の大部分を埋めた

主解析 34 セルでは、WT2 の $\rho$ は 0.77–1.05、中央値 0.92、C4 は 0.64–0.94、中央値 0.85 だった。34 セルすべてが両ドメインで high 判定だった。一方、Frobenius 目的の M3F は $\rho=-0.02$–0.22 で、33 セルが 0.2 未満だった。

（推測）本実験の範囲では、入力分布を用いる TT 最適化によって、TT-SVD から行列低ランク近似までの誤差差の大部分を埋められたと解釈できる。M3F は、M3 から重みの誤差を目的にしたまま ALS を回した対照であり、目的だけを変えない場合には差がほとんど埋まらなかった。ただし、M3F と M5 では sweep 数を同じにそろえていないため、この比較だけから改善量を一つの要因に分解することはできない。

![[assets/04_main_experiment/rho_by_cell.png]]

### 3.2 M2 との差は小さくなったが、多くのセルで残った

$(e_{\mathrm{M5}}-e_{\mathrm{M2}})/e_{\mathrm{M3}}$ は、主解析 34 セルで $-0.03$–$0.16$、中央値は 0.07 だった。負の値は L21 `down_proj` である。NLL では、主解析 34 セルのすべてで M5 が M3 より良かった。一方、M2 との比較では M2 が 32 セルで良く、M5 が 1 セルで良く、1 セルは区間が重なった。M5 と M2 の NLL 差は $+0.0008$–$+0.023$ nat、非圧縮モデルの NLL は 2.552 だった。

この結果からは、M5 は M3 に対して一貫した改善を示したが、M2 はこの比較パネルでほぼ一貫して最良だった、と言える。M5 と M2 の残差は、そのまま TT の到達不能な差を表す事実ではない。M5 の最終停留性が十分でないことと、TT と rank-$r$ 行列が入れ子の表現クラスではないことの両方が、解釈を未確定にしている。

![[assets/04_main_experiment/nll_differences.png]]

### 3.3 TT が M2 を上回る条件も実際にあった

L21 `down_proj` では、WT2 の $\rho$ が 1.01 / 1.05 であり、較正目的でも 1.03 / 1.06 だった。したがって、このセルの逆転は検証分布への移行だけでは説明できない。

rank-$r$ 行列と、指定した TT 形状・ランクの集合は、どちらかが常に他方を含む関係ではない。同じパラメータ数でも、行列が表しやすい重みと TT が表しやすい重みは一致しない。この実測結果は、TT が同一較正目的でも M2 を上回ることが形のうえで起こりうる、と示している。ただし、1 射影・2 予算の結果から、TT が一般に行列より優れるとは言えない。

## 4. 射影ごとに何が違ったか

### 4.1 `q_proj`、`o_proj`、MLP 射影

`q_proj` は主解析 6 セルで WT2 の $\rho$ 中央値 0.95、C4 で 0.93、サブ層出力で 0.92 だった。`o_proj` は 0.91、0.84、0.91 だった。MLP の `gate_proj`、`up_proj`、`down_proj` も、サブ層出力でそれぞれ 0.83、0.87、0.95 と高かった。

事実として、これらでは重み付き出力誤差の改善がサブ層出力まで比較的よく残った。とくに `q_proj` は attention の score、softmax 重み、その後の出力まで $\rho\ge 0.85$ だった。

（推測）これらの射影では、較正時に重く見た入力方向と、実際のサブ層出力に効く方向のずれが比較的小さい可能性がある。**Jacobian** とは、入力の微小な変化が出力へどれだけ伝わるかを並べた微分行列である。確かめるには、各射影について、Gram 行列の固有方向別の残差と、その方向へのサブ層 Jacobian の感度を同じ基底で比較する必要がある。後者は未計測である。

### 4.2 `k_proj`：弱さは attention sink に集中していた

**attention sink** とは、系列の先頭トークンが不釣り合いに大きな attention を受ける現象である。先頭トークンへの attention 割合は、層 7、14、21 でそれぞれ 0.48、0.41、0.69 だった。WT2 と C4 で傾向は似ていた。

`k_proj` は射影直後の WT2 $\rho$ 中央値が 0.90 だったが、サブ層出力では 0.07 まで下がった。追加分析では、score の $\rho$ は 0.82–0.96 だったのに、softmax 重みでは 0–0.14 だった。

当初は、M3 と M5 の差が softmax で無視される成分にある可能性を考えた。しかし、平均シフト成分と対比成分の比率は M2 と M5 でほぼ同じで、例では 0.84 / 0.85、softmax に効く成分だけを測った $\rho$ も 0.79–0.91 だった。この説明は追加分析と整合しない。

代わりに、先頭トークンを除くと softmax 誤差は M2 で 0.01–0.03、M5 で 0.02–0.06、$\rho$ は 0.93–0.96 まで回復した。先頭トークンだけでは M2 の誤差が 0.43–0.71、M5 が 0.72–0.88 だった。つまり、`k_proj` の低い下流 $\rho$ は先頭トークンに集中しており、M2 もその機能を壊している。これは TT 固有の失敗ではない。この条件では「M2 までの差を何割埋めたか」より、すべての圧縮法が sink を保てたかを直接見るべきである。

（推測）先頭トークンの正規化後入力ノルムが他位置の中央値の 0.33–0.46 と小さいことが、`k_proj` の近似でこの位置が軽視される一因かもしれない。ただし、小さいノルムから softmax の破壊までの因果は未確認である。先頭トークンの key 誤差を、score の絶対変化、softmax の温度、query との内積に分解して確かめる必要がある。

### 4.3 `v_proj`：M5 だけが先頭トークンの値を外した

`v_proj` は主解析 3 セルで、WT2 の $\rho$ 中央値 0.79、C4 で 0.69、M5 と M2 の残差 0.15、サブ層出力 0.29、NLL 差 $+0.016$ と、射影別には最も弱かった。なお、主解析の `k_proj` と `v_proj` は 25% 条件各 3 セルだけであり、射影一般の順位としては標本が少ない。

追加分析では、先頭トークンを除いた `v_proj` の $\rho$ は 0.85–0.88 まで回復した。先頭トークンだけの head-output 誤差は、M2 が 0.02–0.04、M3 が 0.03–0.07 だったのに対し、M5 は 0.21–0.86 だった。したがって、今回の `v_proj` で M5 が弱かった直接の場所は、attention sink が大きく読み出す先頭トークンの value である。`k_proj` と異なり、ここでは M5 だけが大きく外した。

（推測）先頭トークンは 1024 トークン中 1 個であるため、較正 Gram 行列では稀な入力方向として扱われ、M5 がその方向に誤差を残した可能性がある。確かめるには、先頭トークン入力を較正 Gram 行列の固有帯域へ射影し、どの帯域に属するかを測る必要がある。これは未計測である。また、較正時に各トークンを出現回数ではなく「受け取った attention 量」で重み付けし、先頭 value の誤差と全体の NLL が改善するかを再実験すれば、仮説を直接検証できる。

## 5. M2 との差はどこに残ったか

### 5.1 C4 で $\rho$ が下がった理由

WT2 から C4 へ移ると、42 セルすべてで $\rho$ が下がった。gap closure は

$$
\rho
= 1 - \frac{e_{\mathrm{M5}}-e_{\mathrm{M2}}}
           {e_{\mathrm{M3}}-e_{\mathrm{M2}}}
$$

とも書ける。分子は M5 と M2 の残差、分母は M3 と M2 の改善可能幅である。

M3 で正規化すると、分子の中央値は WT2 の 0.070 から C4 の 0.105 へ増え、42 セルすべてで増加した。分母の中央値は 0.83 から 0.76 へ減った。一方の項だけを C4 の値へ置き換える反実仮想の分解では、分子だけを変えると中央値は 0.92 から 0.87、分母だけを変えると 0.92 から 0.91 だった。したがって、C4 での低下は主に、C4 上で M5 と M2 の差が広がったためである。

ここでいう**固有方向**とは、較正 Gram 行列を固有分解したときの入力基底であり、固有値が大きいほど較正データで頻繁または強く現れる方向である。固有方向を順位 1–16、17–64、65–256、257 以降に分けると、M3 と M2 の較正誤差差は各帯域に 0.72、0.16、0.14、0.01 の比率で分布した。これに対し、M5 と M2 の較正誤差差は 0.01、0.05、0.24、0.68、C4 では 0.00、0.03、0.18、0.78 だった。

C4 が各帯域を較正データの何倍重く見るかは、順に 0.83、0.82、1.08、1.65 だった。WT2 では 0.95、0.96、0.98、1.07 だった。WT2 から C4 への M5–M2 差の増加は 34 セルすべてで起き、そのうち 257 位以降の帯域から来る割合は中央値 100% だった。34 セル中 30 セルで 90% 以上、最小でも 85% だった。固有基底上の対角近似は、検証 Gram 行列の非対角成分を無視しているが、厳密な差の 88–126%、中央値 96–99% を捉えた。

（推測）M5 と M2 は、同じ較正目的を小さくしても、誤差を残す固有方向が異なる。M5 は較正でほとんど現れない 257 位以降の方向に M2 より多く誤差を残し、C4 がその帯域を相対的に強く数えたため、M5 と M2 の差が広がったと考えられる。この説明は帯域分解と矛盾しない。ただし、固有基底上の対角近似であるため、個々の固有方向間の相関までは説明していない。確かめるには、検証 Gram 行列を含む一般化固有値問題、または非対角項を保った帯域間分解で同じ結論が残るかを確認する。

この結果を「M5 が較正データに過適合した」と表現するのは適切でない。M2 も同じ較正目的を用いているためである。観測されたのは、二つの表現クラスが同じ目的の下で異なる入力方向に誤差を配分したことまでである。

### 5.2 L21 `down_proj` はなぜ逆転できたか

L21 `down_proj` の 25% 条件では、較正の重みで測った M5–M2 差は、固有方向 1–16 位で $+0.00005$、17–64 位で $+0.0010$、65–256 位で $-0.022$、257 位以降で $-0.011$ だった。負は M5 のほうが良いことを表す。50% 条件でも各帯域の符号は同じだった。したがって、M5 が較正目的で M2 を上回ったのは、中位から下位の帯域で得た改善が上位帯域の小さな損失を上回ったためである。

C4 の重みで測ると、257 位以降の M5–M2 差は $+0.041$ に反転した。C4 はこの帯域を較正データの 2.08 倍重く数える。そのため、較正目的では 1 を超えた $\rho$ が、C4 では 1 を下回った。

（推測）M5 は中位から下位の帯域のうち、較正で実際に現れる向きを M2 よりうまく表した一方、同じ帯域内でも較正ではほとんど現れない向きに誤差を残し、C4 がその向きを重く数えた可能性がある。**TT unfolding** とは、TT のモード境界でテンソルを左右二群に分けて行列として見たものである。確かめるには、M2 と M5 の誤差を固有方向別に重み成分へ戻し、TT unfolding の特異ベクトルと中位・下位の固有方向の対応を調べる。また、TT のモード分割を変えて同じ逆転と C4 での再反転が残るかを比較する必要がある。

### 5.3 残りの差は最適化不足か、TT の形か

**停留性**とは、各 TT コアをほかのコアを固定して解き直したとき、なおどれだけ改善余地があるかを表す性質である。最終 M5 の停留性指標 $s_{\max}$ は $5.9\times10^{-5}$–$7.3\times10^{-4}$、中央値 $2.6\times10^{-4}$ だった。[[60_LLM_TT_vs_Matrix/10_Qwen3_0p6B_Base/03_長いALSの収束確認と初期値依存|03 長い ALS]] で用いた $10^{-6}$ の基準には達していない。25% 条件で射影ごとの中央値を比べると `v_proj` が最も大きく、その 3 セルの中央値は $5.1\times10^{-4}$、ほかの射影は $1.3\times10^{-4}$–$4.2\times10^{-4}$ だった。

したがって、保存済みの M5 は研究上の計算予算で停止した解であり、十分な停留点とは確認されていない。M5 は 250–800 sweep、中央値 400 sweep を要した一方、M2 は 1 回の SVD で求まった。この計算量差も、到達誤差と分けて記録すべきである。

一方、初期値を M3 と M4r で変えたときの最終較正目的差は 0.33% 以内で、判定対象 12 セルの分類も同じだった。これは大きな初期値依存が観測されなかった証拠ではあるが、大域最適性の証明ではない。

（推測）現在の M2 との差には、少なくとも「まだコア更新で下げられる分」と「指定した TT 形状で到達する最良値との差」が混在している。両者を見分けるには、まず同じ TT 形状で $s_{\max}\le10^{-6}$ まで解き、複数初期値から同じ目的値へ収束するかを確認する。その後、パラメータ数をほぼ固定してモード分割と TT ランク配分を変える。前者だけで差が縮めば最適化不足が支持され、停留後も形状ごとに系統的な差が残れば TT 形状への依存が支持される。現データだけではこの二つを分離できない。

## 6. 結果から言える範囲

### 言えること

- Qwen3-0.6B-Base の選んだ 42 セルでは、M5 は M3 より重み付き出力誤差を大きく改善し、主解析 34 セルでは NLL もすべて改善した。
- 主解析では、WT2 で M3–M2 差の中央値 92%、C4 で 85% を M5 が埋めた。
- M2 との差の多くは、較正 Gram 行列の下位固有帯域に残り、C4 はその帯域を較正データより強く重み付けした。
- `k_proj` の下流での弱さは attention sink に集中し、M2 も壊れていたため TT 固有ではなかった。
- `v_proj` では M5 だけが先頭トークンの value を大きく外し、これが下流での弱さに対応した。
- L21 `down_proj` では、同じ較正目的でも TT が rank-$r$ 行列を上回る実例があった。

### まだ言えないこと

- 保存済み M5 は停留性基準を満たしていないため、残差が最適化でどこまで縮むかは未計測である。
- 3 層・1 モデル・限られた較正集合の結果から、ほかの LLM、層、タスクへ同じ順位を外挿することはできない。
- `k_proj` と `v_proj` の主解析は 25% 条件各 3 セルだけなので、射影別中央値の順位は暫定的である。
- 重み付き出力誤差、サブ層出力、NLL は同じ量ではない。高い $\rho$ が必ず同じ比率の NLL 改善を生むとは限らない。
- 誤差が下位固有帯域に残った理由が、TT のモード分割、ランク配分、局所最適化、またはそれらの組合せのどれかは未分離である。

## 7. 次の実験で優先して確かめること

### 優先度 1：attention sink を評価設計に入れる

Qwen3 の追加実験では、`k_proj` と `v_proj` について、全トークン平均に加えて先頭トークンと非先頭トークンを分けて保存する。さらに、先頭トークンを「受け取った attention 量」で重み付けした較正 Gram 行列を試す。

これにより、`k_proj` では全方式が sink を壊す問題、`v_proj` では M5 だけが先頭 value を外す問題を、通常の平均誤差から分離できる。既存データで確認できたのは分離評価までであり、重み付け較正の効果は新しい計算が必要である。

### 優先度 2：停留性と TT 形状を段階的に分離する

代表セルとして、弱かった `v_proj`、典型的なセル、M5 が M2 を上回った L21 `down_proj` を選ぶ。まず現在と同じ形状で $s_{\max}\le10^{-6}$ まで解き、次にパラメータ数をそろえてモード分割とランク配分を変える。

Pythia-410M に移る前に少数セルでこの手順を行えば、モデル差と最適化差を同時に変えずに済む。全 42 セルの長時間実行は、その結果を見てから判断できる。

### 優先度 3：Pythia-410M で再現性を測る

Pythia では、同じ M1–M5、同じ $e$ と $\rho$、同じ WT2 / C4 評価を保ち、次も保存する。

- 固有帯域別の M3–M2 差と M5–M2 差
- 先頭トークンと非先頭トークンを分けた attention 誤差
- サブ層出力と、次トークン予測の負の対数尤度である NLL
- 最終 $s_{\max}$、sweep 数、初期値
- 各方式の実時間とピークメモリ

この再現実験で問うべきなのは、Qwen3 と同じ数値になるかではない。M5 が M3 から大きく改善すること、残差が下位固有帯域に偏ること、attention sink が `k_proj` / `v_proj` の例外を作ること、TT が M2 を上回るセルが存在しうることのうち、どれが別モデルでも観測されるかである。

## 8. まとめ

本実験で M5 は、M3 と M2 の差の大部分を埋め、NLL でも M3 を全主解析セルで改善した。一方、M2 との差は多くのセルに残り、その差は C4 が強く見る下位固有帯域で広がった。attention 射影の例外は一様ではなく、`k_proj` では全圧縮法が attention sink を壊し、`v_proj` では M5 が先頭 value を外した。

重要なのは、M2 がほぼ一貫して良かったことと、L21 `down_proj` で TT が較正目的でも M2 を上回ったことが両立している点である。現在の結果は、TT が行列にかなり迫ったこと、同じパラメータ数でも両者が誤差を残す方向は異なることを示している。残りの差を最適化と TT 形状へ分けるには、停留性をそろえた追加実験が必要である。
