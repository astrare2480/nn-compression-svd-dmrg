## 1. 修正

### 1.1 【バグ】`output_error_ratios` の Gram と活性化の取り違え
- 場所：`src/nn_compression/compression/metric_low_rank.py` の `output_error_ratios`
- 問題：入力が「入力次元 × 入力次元の正方行列」なら Gram 行列として扱っている。1文書分の活性化は 1024 トークン × 1024 次元で正方行列になるため、活性化を渡すと Gram として誤って計算される。
- 修正：形で判別するのをやめ、**Gram 用と活性化用の関数に分ける**（例：`output_error_ratios_from_gram`、`output_error_ratios_from_activations`）。Notebook の `metric_bundle` も、どちらを渡すかを明示する形に直す。
- テストを追加する：1024×1024 の活性化を渡したとき、活性化から直接計算した値と一致すること。同じ活性化から作った Gram を渡したときとも一致すること。
- 古い `output_error_ratios` は、どこからも使われていなければ削除してよい。残す場合は、正方行列を受け取ったら `ValueError` にする。

### 1.2 M5 の「M4 から始める」初期値の記録
- 背景：対角スケール D⁻¹ は、bond 次元を変えずに TT のコアへ吸収できない（1回目の依頼文の「吸収する」は誤りだった）。現在の実装（M4 の行列を密に戻し、同じ rank でもう一度 TT-SVD する）は妥当なので、**方法はこのままでよい。**
- 修正：記録上の名前と記録項目を変える。
  - 初期値の名前は `M4` ではなく `M4_retruncated` とする（`adopt_lower_calibration_q` の候補名、保存ファイル、CSV の列を含む）。
  - 初期値ごとに、ALS を始める前の較正データの Q_λ を記録する。M4 そのもの（(TT, D⁻¹) の組）の Q_λ と並べ、作り直しでどれだけずれたかが分かるようにする。
  - docstring の「`D^{-1}` を吸収したコア」という表現を「M4 の密行列を TT-SVD で作り直したコア」に直す。

### 2.1 主実験
- 条件：T1・T2 × 予算 50%・25% × M5 の初期値2通り（M3、M4_retruncated）= M5 を8本。M1〜M4 はすべての組み合わせで計算する。
- M5 は、較正データの Q_λ が小さい方の初期値を採用する（事前の規則。同点なら M3）。採用しなかった方の結果も記録する。
- 誤差は、較正（正則化なしの Q と Q_λ）、同じドメインの検証、別ドメインの検証で計算する。**文書ごとの分子と分母を残す**（ブートストラップ用）。
- ブートストラップで出す差：g = e(M3) − e(M2)、e(M3) − e(M5)、e(M5) − e(M2)。各データで計算する。
- E_gated も同じように計算する。そこから同じ式で ρ_gated を計算するが、判定には使わない。
- 1層置換の perplexity：元のモデル、M1〜M5（M5 は採用した方）について測る。
- 判定：`evaluate_rho` と `classify_pilot_outcome` で機械的に出す。
- 長時間かかるので、**M5 は1本終わるごとに結果をファイルに保存し、途中で止まっても、終わった分から再開できるようにする。**

### 2.2 較正量の感度確認（範囲を今回確定）
