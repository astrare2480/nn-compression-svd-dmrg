## 2. 実験の要点（前提として使う）

**何を比べたか**：モデルの中の重み行列 1 枚を、パラメータ数を元の 50% か 25% に減らした近似に置き換える。良し悪しは、その層の**出力**の誤差で測る。

$$e=\frac{\|(W-\hat W)\,G^{1/2}\|_F^2}{\|W\,G^{1/2}\|_F^2}$$

- $W$ は元の重み、$\hat W$ は近似、$G$ は入力の Gram 行列（入力ベクトルの二次モーメント $X X^\top$）。$e$ は検証データの入力で測る。
- **較正データ**（近似を作るのに使った入力）は WikiText-103 train の 128 系列。
- **検証データ**は、WikiText-2 validation の 59 記事（較正と同じ系統）と、C4 validation の 128 文書（ウェブの文章。別の系統）。

**用語**：

- **層**：Qwen3 は同じ形の層を 28 段重ねたもの。そのうち 7・14・21 層を選んだ。目的は、深さによらず同じ結論になるかを見ることで、層そのものを調べたかったわけではない。
- **射影**：1 つの層の中にある重み行列 7 枚。
  - attention ブロック：q、k、v、o
  - MLP ブロック：gate、up、down
- **セル**：「層 × 射影 × 予算」の組。全部で $3 \times 7 \times 2 = 42$。各射影は 6 セル（3 層 × 2 予算）を持つ。
- **サブ層の出力**：射影 1 枚を置き換えたときの、attention ブロック全体または MLP ブロック全体の出力（残差を足す前）。

**方式**：

| 記号 | 中身 |
|---|---|
| M1 | 普通の SVD（重みの誤差だけを見る行列） |
| M2 | 白色化 SVD。決められたランクの行列の中で、較正データでの出力の誤差 $Q_\lambda$ を最小にする（Eckart–Young で最適が保証される） |
| M3 | 普通の TT-SVD（重みの誤差だけを見る TT） |
| M3F | M3 から、重みの誤差のまま ALS を回した TT（対照） |
| M4 / M4r | 入力のチャネルの大きさで重みをつけた TT-SVD（補助、初期値の比較用） |
| M5 | M3 から、出力の誤差 $Q_\lambda$ を ALS で下げた TT（主役） |

$Q_\lambda$ は、較正データでの出力の二乗誤差。Gram 行列に小さな正則化 $\lambda\,\mathrm{tr}(G)/n\cdot I$ を足す（主な値は $\lambda = 10^{-6}$）。

**物差し**：TT の基本（M3）と行列の最良（M2）の差を「溝」とし、M5 がその何割を埋めたかを

$$\rho=\frac{e_{M3}-e_{M5}}{e_{M3}-e_{M2}}$$

で測る。$\rho = 0$ なら埋まらない、$1$ なら M2 に追いつく、$1$ より大きければ M2 を超える。

**主な集計の 34 セル**：42 セルから、結果を見る前に 8 セルを外した。

- **k と v の 50%（6 セル）**：k・v の行列は 1024×1024 で、ほかより小さい。そのため 50% の予算では、TT の 1 つ目の切れ目の太さ（ボンドランク）が 63 になり、上限 64 にほぼ達する。その切れ目は圧縮の役目を果たさず、TT としての比べ合いにならない。
- **L14 の up（2 セル）**：予備実験の開発に使ったセル。

その結果、主な集計の k と v は、それぞれ 25% の 3 セルだけになる。

## 4. 分かったこと（事実）

1. **溝の大半が埋まる。**
   - $\rho$ は WikiText-2 で 0.77〜1.05（中央値 0.92）、C4 で 0.64〜0.94（中央値 0.85）。
   - 主な 34 セルは両ドメインで全部 high。判定 W・B・F はすべて成立した。
2. **効いているのは「目的を出力の誤差にしたこと」で、反復の計算量だけでは説明できない。**
   - 重みの誤差のまま回した M3F の $\rho$ は −0.02〜0.22 で、33 セルで「2 割未満」が区間で支持された。
   - ただし、言葉の決まりにより「主因は目的関数」とは書かない。
3. **条件にあまり左右されない。**
   - 初期値：M3 からでも M4r からでも、較正の $Q_\lambda$ で 0.33% 以内の解に収束し、分類も同じ（12 セル）。
   - $\lambda$：別の値（$10^{-7}$、$10^{-5}$）でも、分類は変わらなかった。
   - 予算・層：$\rho$ の中央値は、予算でも層でも 0.91〜0.93（WikiText-2）でほぼ同じ。
4. **それでも M2 にはほぼ届かない。結論として、この設定では M2（行列の最良）が最強。**
   - $e_{M5}-e_{M2}$ は 42 セル中 40 で区間ごと正。大きさ $(e_{M5}-e_{M2})/e_{M3}$ は、主な 34 セルで −0.03〜0.16（中央値 0.07。負は L21_down）。
   - NLL（1 つの射影だけ置き換えた WikiText-2 の NLL。元のモデルは 2.552）では、M5 は M3 より 34 セルすべてで良い。M2 との比べでは、32 セルで M2 が良い（+0.0008〜+0.023 nat）。
   - M2 は SVD を 1 回するだけで作れるが、M5 は ALS を数百掃引回す（M5 の掃引数は 250〜800、中央値 400）。精度でも手間でも M2 が上。
   - M2 を上回ったのは L21_down の WikiText-2 だけ（$\rho$ = 1.01・1.05）で、C4 では 1 を下回った。
   - **L21_down は、較正データの目的 $Q_\lambda$ そのものでも M2 を上回っている**（較正での $\rho$ = 1.03・1.06）。M2 が最適なのは「決められたランクの**行列の中で**」であって、TT はそれとは別の形の集まり（どちらかがどちらかに含まれる関係ではない）なので、同じパラメータ数で TT が M2 に勝つことはありうる。「評価データが較正と違うから逆転した」という説明は誤り。
5. **C4 では、42 セルすべてで $\rho$ が WikiText-2 より低い。** 意味は「C4 で測ると、M5 は M2 から少し余計に離される」。
   - 分子と分母に分けて確かめた（§6.5 の分析 0）。42 セルすべてで、分子 $(e_{M5}-e_{M2})/e_{M3}$ が増え（中央値 0.070 → 0.105）、分母 $(e_{M3}-e_{M2})/e_{M3}$ が減った（0.83 → 0.76）。片方だけ C4 の値に替えると、$\rho$ の中央値は分子だけで 0.92 → 0.87、分母だけで 0.92 → 0.91。**下がったのは主に分子**。M2 の M3 に対するリードも C4 では少し縮む。

## 6. ユーザーと確認した解釈（考察の中心にしてほしい）

### 6.1 M2 が最強、では「残りの差」は何か

- 結論として、**今回の条件での実測では**、M2 がほぼ一貫して最良だった。「M2 があらゆる同じパラメータ数の表現の中で最適」という意味ではない。M2 が最適なのは、決められたランクの行列の中で、較正データの目的 $Q_\lambda$ について。
- 実際、L21_down では較正データの目的でも M5 が M2 を上回った（§4 の 4）。TT が行列に勝つことは、形のうえでは起こりうる。
- 残る問いは「TT が M2 を超えられる見込みがあるか」。M2 との残りの差には、少なくとも次が混ざっている。
  - **最適化の不足**：TT の中に良い解があるのに、ALS が見つけていない。最終の M5 は停留点ではない（§6.5 の分析 0）。
  - **今の TT の形（切り方・ランクの配分）**：その形での最良の解でも M2 に及ばない。
  - **較正と評価の違い**：§6.3。
- これらは今のデータでは分けられない（未検証）。どれであっても、今回の結論（この条件では M2 が最良）は変わらない。
- 区別の手がかりの案：代表セルで、2 サイト更新・別の最適化法・複数の初期値で $Q_\lambda$ がさらに下がるか。切り方を変えると大きく良くなるか（そうなら「TT 一般」ではなく「今の切り方」の問題）。

### 6.2 k：崩れるのは先頭のトークン（attention sink）。TT に固有ではない

- 事実（§6.5 の分析 2・3）：
  - 点数（softmax の前）の段階までは、M5 は溝をよく埋める（$\rho$ 0.82〜0.96）。softmax の後の重みで、$\rho$ は 0〜0.14 に落ちる。
  - 点数の誤差を「全部の key に同じだけずれる成分（softmax が無視する）」と「key の間の差を変える成分」に分けても、効く成分の割合は M2 と M5 でほぼ同じ（例：0.84 と 0.85）。効く成分だけで見ても $\rho$ は 0.79〜0.91。**「M5 は無害な向きの誤差ばかり減らした」という説明は外れ**。
  - 注目の 41〜69% は、区間の先頭のトークン 1 つに集まっている（attention sink）。
  - 置き換えた k を**先頭以外だけ**に使うと、softmax 後の重みの誤差は M2 0.01〜0.03、M5 0.02〜0.06 と小さく、$\rho$ は 0.93〜0.96。**誤差のほぼ全部は、先頭のトークンの k から来る**。
  - 先頭のトークンの k は、**M2 でも壊れる**（先頭だけ置き換えたときの重みの誤差は M2 0.43〜0.71、M5 0.72〜0.88）。
- 解釈：25% まで圧縮すると、どの方式でも先頭のトークンの k が壊れ、注目の配分が崩れる。k のサブ層の $\rho$ が低いのは「TT が softmax の先に届かない」からではなく、「全方式が壊れている所で比べているので、$\rho$ に意味がない」から。k の問題は TT 固有ではなく、圧縮そのものの問題（推測ではなく、上の事実からの読み）。
- 未解決：なぜ先頭のトークンの k がこれほど壊れやすいのか（先頭のトークンの入力は、正規化の後ではほかの位置より小さい：ほかの位置の中央値の 0.33〜0.46 倍）。

### 6.3 C4 で下がる：M5 は「較正でほとんど来ない入力の向き」に誤差を残す

- 事実（§6.5 の分析 1）：較正の Gram 行列の固有方向を、較正データでよく来る順に並べると：
  - 溝（M3 と M2 の差）の 72% は、上位 16 個の向きにある。M5 はそこをほぼ埋める。
  - M5 が M2 より余計に残した誤差の 68% は、257 位以降（較正でほとんど来ない向き）にある。
  - C4 は 257 位以降の向きを、較正より 1.65 倍重く数える（トークンあたり）。WikiText-2 は 1.07 倍。上位の向きは、C4 では 0.83 倍と軽い。
  - C4 で「M5 と M2 の差」が増えた分は、ほぼ 100% が 257 位以降から来る（34 セルすべてで増加）。
  - down が一番極端（L7・L14 の down）：M5 は 65〜256 位の向きでは M2 より誤差が少ないのに、257 位以降で大きく負ける。C4 の 257 位以降の重みは down の中央値で 1.82 倍。C4 で down の $\rho$ が大きく下がる理由。
  - **L21_down は違う形**：較正の重みでは、M5 は 65〜256 位（−0.022）と 257 位以降（−0.011）の両方で M2 より誤差が少ない（25%。50% も同じ符号）。だから較正の目的でも M2 を上回る。ところが C4 の重みで測ると、257 位以降の差が +0.041 に反転する（C4 はその帯を較正の 2.08 倍重く数える。帯の中で、較正ではほぼ来ない向きに M5 の誤差が残っているため）。だから C4 では $\rho$ が 1 を下回る。
  - C4 で増えた「M5 と M2 の差」のうち 257 位以降から来る割合は、中央値 100%（34 セル中 30 セルで 90% 以上、最小 85%）。
- 帯ごとの「M5 ÷ M2」（分析 4）：1〜16 位 4.6 倍、17〜64 位 4.0 倍、65〜256 位 1.6 倍、257 位以降 1.35 倍。倍率が大きいのは上位の帯だが、M2 は上位をほぼ完全に表すので、差の絶対値は小さい。257 位以降は M2 自身の誤差の大部分がある帯で、M5 はそこで 3〜4 割多い。それが差の大部分になる。
- 解釈：較正の目的では、ほとんど来ない向きの誤差はほぼ数えられない。**M2 も M5 も**そこを大きく雑に扱い、M5 のほうが 3〜4 割多く雑（「M5 だけがそこに誤差を残し、M2 は残さない」ではない。理由は未解決。M2 も同じ目的の最適解なので「M5 が較正に合わせ込みすぎ」という言い方は不正確。「誤差の残し方（どの向きに残るか）が M2 と M5 で違う」と書く）。C4 はその向きを重く数えるので、差が開く。
- 分母が減る（M2 のリードが縮む）のも、溝が上位の向きにあり、C4 がそこを軽く数えるため、と読める。
- 補足：ここで合わせ込むのはモデル全体ではなく、圧縮した 1 枚の行列。モデルの学習はしていない。M1・M3 は重みだけを見るので、データに合わせた得も、外れたときの損もない。
- 確かめ方の案：C4 で較正し直して、C4 での $\rho$ が上がるか（新しい ALS が要る。代表セルから）。

### 6.4 v：M5 だけが先頭のトークンの値を外す

- 事実（§6.5 の分析 3）：
  - 置き換えた v を**先頭だけ**に使うと、head ごとの出力の誤差は M2 0.02〜0.04、M3 0.03〜0.07 に対し、**M5 は 0.21〜0.86**。M5 だけが先頭のトークンの値を大きく外す。
  - その外れた値が、注目の 41〜69% を通じて全部の出力に写し込まれる。先頭への注目が一番多い L21（69%）で、M5 が M3 より悪くなった。
  - **先頭以外だけ**に使うと、$\rho$ は 0.85〜0.88（WikiText-2）で、ほかの射影と同じくらい。
- 解釈（推測）：先頭のトークンは 1,024 トークンに 1 回しか来ないので、較正の Gram 行列では「ほとんど来ない向き」に当たる。§6.3 のとおり、M5 はそういう向きに誤差を残す。だから先頭のトークンの値を外す。k の問題（§6.2）とは違い、v の問題は M5（TT＋ALS）に固有。
- 確かめ方：先頭のトークンの入力が、較正の固有方向のどの帯にあるかを測る（短い計算）。改善の案：較正の目的で、先頭のトークンを注目される量に応じて重く数える。
