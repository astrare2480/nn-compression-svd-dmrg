## 4. 元資料の混乱・誤記をそのまま採用しない

- $Q^T(Q^T)^T$ は $Q^TQ$。$QQ^T$ と取り違えた途中発言は採用しない。
- 「左右の違いは添字の置き方」は**ブロック状態のGramの表現方法**についての説明である。同じ内部コアの左・右直交条件の同値性とはしない。
- 3階の $G_3$ をそのまま転置したような曖昧な表記は使わず、右行列 $A_3=G_3(:,:,1)$ を定義してから転置する。
- QRの三角因子と右ブロックを $T_k$ / $\mathcal R_k$ で分離。以前の $L_2=U\otimes I$ と2コア左ブロックも $\mathcal L_2$ で分離。
- reduced QRの新ボンド次元は一般には $q=\min(m,n)$。元の列数・rankと常に同一とはしない。rank欠損入力・符号の非一意性・微分の注意を補足。
- $A^TA$ を右物理空間への直交射影と呼べるのは、$AA^T=I$ を満たす右直交化後である。
- 右sweepは因子を右から左へ送る。「右直交化」と「右向きのsweep」を同一視しない。
- 中心コアには直交条件を課さないのであり、必ず非直交であるとは言わない。
- 左右QRは同じ元TTへ適用し、各因子を1回ずつ中央へ吸収する。異なる枝のコアの混在では全体不変性を保証しない。
- NNへdense重みを再構成して戻すだけの正しさ確認と、実行時parameter/MACsを減らす因子化層を区別する。TT-SVDと既存TTのroundingの役割も分離。
