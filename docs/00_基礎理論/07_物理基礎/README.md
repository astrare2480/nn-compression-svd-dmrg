# 物理基礎

TTを量子多体系のMPSとして読むための基礎を扱う。テンソルの行列化、QR、収縮、誤差の導出そのものは [[00_基礎理論/01_数学基礎/02_テンソル代数/30_TT_MPSの定義]] 以降に残し、ここでは物理添字・ボンド状態・Schmidt分解・縮約密度行列・直交中心の意味を明確にする。

## 読む順番

1. [[00_基礎理論/07_物理基礎/16_TT_MPSの物理解釈_縮約密度行列と局所写像]]：物理添字、bond dimension、Schmidt係数、密度行列、局所写像。
2. [[00_基礎理論/07_物理基礎/42_MPS正準形と直交中心の物理的意味]]：左右のブロック状態、直交中心、QRによる基底の更新、Schmidt分解との違い。
3. [[00_基礎理論/07_物理基礎/44_Schmidt打ち切りとボンド状態の物理的意味]]：打ち切りをSchmidt状態の射影として読み、捨てた重みと再規格化を区別する。

対応する数学的導出は [[00_基礎理論/01_数学基礎/02_テンソル代数/36_TT_MPSのGauge自由度と左QR直交化]] から [[00_基礎理論/01_数学基礎/02_テンソル代数/41_TT_MPSの直交中心の移動]] へ進む。小さいTensorを使うPyTorchの操作は [[40_TensorTrain_MPS/README]] に分ける。実装したことと物理的意味を理解したことを同一視しない。
