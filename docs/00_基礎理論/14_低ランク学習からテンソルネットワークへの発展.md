# 低ランク学習からテンソルネットワークへの発展

## サマリー

Fashion-MNISTで実施したのは、学習済み重みをSVDで圧縮し、その低rank構造をFine-tuningする段階まで。

PDFで整理した発展の流れは、

```text
通常の重み行列
→ 学習後SVD
→ 層ごとのadaptive rank
→ 圧縮後Fine-tuning
→ 最初から低ランク構造で学習
→ MPO / Tensor Train / DMRG型の重み表現
```

である。

## 1. 学習後SVD

フルrankモデルを学習した後で重み行列をSVDし、低rank近似へ置き換える。

問いは、

> 学習済みモデルの重みには、どれだけ削っても性能を保てる冗長性があるか。

## 2. SVD後Fine-tuning

SVDは元の重みへの近さを最適化するが、分類lossを直接最小化するわけではない。
そこでrankを固定したまま低rank因子を追加学習し、task lossへ再適応する。

## 3. 最初から低ランク構造で学習

さらに進むと、フルrank重みを一度作ってからSVDするのではなく、最初から小さな低rank因子の積としてモデルを持ち、その因子を学習する。

PDFでは `SVD-training / LoRA的な低ランク学習` という方向として整理している。

```text
post-training SVD
→ 学習済みモデルの冗長性を見る

最初から低ランク学習
→ 必要な表現を低自由度構造だけで学べるかを見る
```

今回のFashion-MNIST実験ではこの段階は未実施。

## 4. テンソルネットワークへの発展

SVD低ランク近似は、大きな行列を2つの小行列へ分ける。

その先では、

- Matrix Product Operator（MPO）
- Tensor Train
- DMRG型の重み表現

のように、より多くの小さなテンソルへ分解する方向へ発展できる。

今回のFashion-MNIST結果からMPO / Tensor Train / DMRGの性能を直接主張することはできない。
今回の実験はその前段階として、「学習済み重みを低自由度化してもどこまで性能を保てるか」を測るもの。

## 5. 次へ持ち越せる観点

- 特異値スペクトルとretained energy
- rankとtask lossの関係
- 圧縮率とtask性能のPareto関係
- SVD直後とFine-tuning後の差
- 層ごとに必要なrankが異なる可能性
